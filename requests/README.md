# Request inbox

Drop WhatsApp change requests here, then run `/site-update` in Claude Code.

## Easiest way: export the chat
In WhatsApp, open the group → group name → **Export chat** → **Without media** →
save or AirDrop the `.txt` into this folder. Then run `/site-update`.

## Or just paste
Run `/site-update` and paste the messages straight in. No file needed.

Processed files are recorded in `../CHANGELOG.md`.
